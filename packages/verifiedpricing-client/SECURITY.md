# Security reporting

Do not post API keys, private configuration, report tokens or private responses
in public issues. Use a private reporting channel agreed directly with the
repository owner. No monitored security mailbox or response-time promise is
advertised by this early-access package.

Include package/Python/OS versions and a minimal reproduction using synthetic
credentials. Credential files, origin validation, redirects and error handling
are security boundaries. API pilot keys are issued separately; configuring a
REST key is not OAuth or browser sign-in. Never share one owner's key among
unrelated users.
